# Demo and setup

Use Node 22.13 or later. In the repository root, run `npm ci`, copy `.env.example` to `.env` only if no local `.env` exists, then run `npm run dev`. Open `http://127.0.0.1:5173/panel.html` and select **Discover**. Find stays the default. Reading pages are development-only and are excluded from the extension build; opted-in measurement runs independently of the Discover view.

Privately configure `OPENAI_API_KEY` for direct-provider synthesis. Never include its value in wiki pages, logs, screenshots, chat, or commits. Preserve the team’s model configuration. Use an isolated rehearsal database. Optional live search configuration is separate from synthesis.

Without a key, explicitly select **Show prepared rule-based demo** and label it as such. Live AI has not been verified merely because the UI or mock-provider tests work.

## Three-minute Part 4 slice

| Time | Show |
| --- | --- |
| 0:00–0:25 | Explain fragmented context and enable the two consents. |
| 0:25–0:55 | Dwell in each marked recipe/commute reading region. State that these are prepared sources on the same origin. |
| 0:55–1:20 | Review durations and saved summaries; explain that attention is uncertain. |
| 1:20–1:50 | Explicitly connect with AI; inspect citations and uncertainty or an honest abstention. |
| 1:50–2:25 | Confirm a current need with constraints; show one labelled offer. No purchase occurs. |
| 2:25–3:00 | Correct, remove evidence, or pause; show the old result withdrawn. |

For a seven-minute team pitch: 45 seconds problem, 1 minute existing cursor flow, 3 minutes Part 4, 1 minute results/voice, 45 seconds separate seller direction, 30 seconds close. Teammates present their own work. Do not imply the seller/model service consumes the demonstrated context.
